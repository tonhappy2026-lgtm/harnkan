# หารกัน (HarnKan)

แอพเว็บแบบ PWA สำหรับ iPhone ใช้หารค่าอาหารเวลาไปกินหลายคน **ทำงานออฟไลน์บนเครื่องเดียว** พร้อมสร้าง **QR PromptPay** รายคน

## ฟีเจอร์หลัก
- **หารเท่ากัน** หรือ **หารตามรายการ** (เลือกคนที่กินแต่ละเมนูได้)
- เปิด/ปิด **Service charge (10%)**, **VAT (7%)**, ตัวเลือก **ราคารวม VAT แล้ว** และ **ส่วนลด (บาท / %)**
- คำนวณละเอียดเป็นสตางค์ กระจายเศษด้วยวิธี Largest Remainder ให้ผลรวมตรงกับยอดบิล 100%
- สร้าง **QR PromptPay** ระบุยอดเงินรายคนในเครื่อง (ไม่ต้องต่อเน็ต)
- ติ๊ก **"จ่ายแล้ว"** รายคน พร้อมคำนวณยอดค้างจ่าย
- แชร์สรุปเป็น **ข้อความ** (คัดลอกส่ง LINE) หรือ **รูปภาพการ์ดสรุป**
- บันทึกประวัติบิล รายชื่อเพื่อนประจำ และสำรองข้อมูลเป็นไฟล์ JSON (Export / Import)
- รองรับ **ภาษาไทย / อังกฤษ** และโทน **สว่าง / มืด** ตามเครื่อง iOS

## วิธีติดตั้งบน iPhone
1. เปิดลิงก์ GitHub Pages (`https://<username>.github.io/harnkan/`) ใน **Safari**
2. แตะปุ่ม **แชร์ (Share)** ด้านล่าง
3. เลือก **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)**
4. เปิดแอพ **หารกัน** จากหน้าจอโฮม (ใช้งานออฟไลน์ได้ทันที)

## การพัฒนาในเครื่อง
```bash
npm install
npm run dev      # เปิดเซิร์ฟเวอร์พัฒนา
npm test         # รันชุดทดสอบ Vitest ทั้งหมด
npm run build    # สร้างไฟล์สำหรับใช้งานจริงในโฟลเดอร์ dist/
```

## การเปิดใช้งาน GitHub Pages
1. สร้าง repository ชื่อ `harnkan` บน GitHub แล้ว push โค้ดขึ้น branch `main`
2. ไปที่ **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
3. เมื่อ push ขึ้น `main` ระบบจะรันทดสอบและ deploy อัตโนมัติ
